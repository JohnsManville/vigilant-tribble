## Ops gotchas (learned the hard way)
- Deploy: `npm run build && npx wrangler pages deploy dist --project-name bitsies-scene-builder-app --branch main --commit-dirty=true`
- After deploy, apex can serve the OLD bundle ~15–20s. Verify:
  `curl -s <url>/ | grep -o 'index-[A-Za-z0-9_-]*\.js'` vs local build hash.
- Never use `CF_PAGES` to detect prod — `wrangler pages dev` sets it locally too.
- Scene ids must include `crypto.randomUUID()` (ms-only id collided under concurrency).
- Prod deletes/migrations require naming the DB + action explicitly (classifier gate). Correct.
- Two Pages projects exist: `bitsies-scene-builder` (old prototype), `bitsies-scene-builder-app` (prod).
